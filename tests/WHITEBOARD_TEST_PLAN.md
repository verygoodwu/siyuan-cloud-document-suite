# 白板完整测试方案

## 完成标准

只有以下四层全部通过，才允许报告“白板测试完成”：

1. 数据模型与几何单元测试全部通过。
2. 插件整体回归测试全部通过，表格、脑图和导入功能不得回退。
3. 真实 Chromium 浏览器中的白板完整交互测试全部通过。
4. 构建、打包、本地 API 安装及安装后静态资源校验全部通过。

## 白板交互规则

- 单击节点：只选中，不进入编辑，不创建新节点。
- 双击可输入节点：进入文字编辑，不增加节点数量。
- 新建矩形、椭圆、菱形、便签或文本：创建后立即进入输入。
- 选中可输入节点后直接打字：以输入字符替换原文字并进入编辑。
- Enter/F2：编辑当前节点；Ctrl+Enter 或点击外部：提交；Esc：取消。
- 双击空白画布：不隐式创建节点，避免连续点击误创建。
