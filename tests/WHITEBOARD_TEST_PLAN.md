# 白板完整测试方案

## 完成标准

只有以下四层全部通过，才允许报告“白板测试完成”：

1. 数据模型与几何单元测试全部通过。
2. 插件整体回归测试全部通过，表格、脑图和导入功能不得回退。
3. 真实 Chromium 浏览器中的白板完整交互测试全部通过。
4. 构建、打包、本地 API 安装及安装后静态资源校验全部通过。
5. 严格交互、2,000 节点真实 DOM 性能和 30 分钟稳定性测试全部通过；物理设备或 NAS 未实测时必须明确标注，禁止用模拟结果替代。

## 白板交互规则

- 单击节点：只选中，不进入编辑，不创建新节点。
- 双击可输入节点：进入文字编辑，不增加节点数量。
- 新建矩形、椭圆、菱形、便签或文本：创建后立即进入输入。
- 选中可输入节点后直接打字：以输入字符替换原文字并进入编辑。
- Enter/F2：编辑当前节点；Ctrl+Enter 或点击外部：提交；Esc 首次取消编辑，后续依次取消选择、回到选择工具。
- 双击空白画布：不隐式创建节点，避免连续点击误创建。
- 节点拖动小于 5 屏幕像素时仍按单击处理，避免抖动误移；Alt+拖动只在超过阈值后复制。
- 快捷创建点单击按固定间距创建，拖动显示预览并按松开位置创建；四个方向行为一致。
- 普通滚轮平移，Ctrl/Meta+滚轮按指针位置缩放；`1` 适应全部内容，`2` 适应所选内容。

## 必测矩阵

| 编号 | 范围 | 必测内容 | 通过标准 |
| --- | --- | --- | --- |
| WB-01 | 打开 | 新文件、已有文件、损坏文件、未来版本 | 正常打开或给出安全错误，不丢数据 |
| WB-02 | 创建 | 矩形、椭圆、菱形、便签、文本、图片、画笔 | 节点类型和几何正确，文字型节点立即输入 |
| WB-03 | 输入 | 单击、双击、直接打字、Enter/F2、Ctrl+Enter、Esc、失焦、CDP 真实字符输入 | 行为符合上方交互规则；真实可编辑层获得焦点；编辑框与节点中心坐标一致；输入能回写节点 |
| WB-04 | 选择 | 单选、Shift 多选、框选、取消选择 | 选区数量及边界正确，不误创建节点 |
| WB-05 | 几何 | 防误拖阈值、拖动、Alt 拖动复制、四角缩放、方向键微调、吸附辅助线 | 节点与自由画笔几何更新，可撤销，缩放后阈值稳定 |
| WB-06 | 连线 | 手动连接、四向快捷点、点击/拖动创建、Tab/Shift+Tab、目标高亮、端点重连、连线文字 | 端点绑定节点，节点移动后连线跟随，标签可保存和导出 |
| WB-07 | 样式 | 填充、边框、文字色、字号、粗体、连线类型 | 即时显示并持久化 |
| WB-08 | 排版 | 六向对齐、横纵分布、横纵网格自动排版 | 坐标确定且无 NaN/重叠异常 |
| WB-09 | 组织 | 分组、取消分组、分区、分区移动 | 引用正确，保存重载后关系仍在 |
| WB-10 | 图层 | 顶层、底层、上移、下移 | 节点顺序按操作变化 |
| WB-11 | 模板 | 流程图、头脑风暴、项目计划 | 节点和连接引用完整，可继续编辑 |
| WB-12 | 编辑命令 | 撤销、重做、复制、粘贴、复制节点、删除 | 数量和内容正确，引用不悬空 |
| WB-13 | 画布 | 空格/中键/右键平移、普通滚轮平移、Ctrl 滚轮缩放、按钮缩放、适应内容与所选内容 | 视口有限值、范围 10%–400%，缩放锚点稳定 |
| WB-14 | 导出 | SVG、PNG | 可生成非空文件，SVG 引用完整 |
| WB-15 | 保存 | 自动保存、Ctrl+S、写后校验、刷新恢复 | 远端附件内容与当前状态一致 |
| WB-16 | 稳定性 | 多页面冲突、删除远端附件、保存失败 | 不静默覆盖，不复活已删除附件，有明确状态 |
| WB-17 | 性能 | 2,000 节点序列化、5,000 节点上限 | 在预算内完成，超限安全拒绝 |
| WB-18 | 集成 | 右键创建、iframe、版本缓存、明暗主题 | 插件可加载，资源版本一致，不影响表格和脑图 |

- `tests/whiteboard-stress-browser.html`：真实持续 30 分钟的拖动、缩放、撤销、重做和保存并发稳定性。
- `tests/whiteboard-cdp-input.mjs`：WB-03 的真实 Edge 焦点、像素居中、字符输入与失焦回写。
- `tests/siyuan-file-store.test.mjs`：WB-15、16。
- `tests/whiteboard-browser-smoke.html`：核心路径快速冒烟。
- `tests/verify-installed.mjs`：本地 API 安装后的版本、启用状态、逐文件哈希与静态资源检查。
- 全量 `node --test --test-isolation=none`：插件回归层。
