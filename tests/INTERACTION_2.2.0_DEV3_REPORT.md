# 2.2.0-dev.3 轻量优化与回归记录

日期：2026-09-15。基线：本地 2.2.0-dev.2（正式版 2.1.14 仅更新说明）。本次保持本地开发，未安装到用户思源、未提交或上传集市。

## 完成内容

- 文本编辑：按内容缓存行索引，光标位置使用二分查找；缓存字节统计，避免点击时重复编码全文；关闭 HTML 预览时不再创建预览更新定时器。换行、Unicode 和原附件字节保存方式保持不变。
- 白板保存：视图变化立即标记待保存，连续平移/缩放在停顿 1.2 秒后合并保存；内容编辑仍走原 700 ms 保存通路。页面隐藏时可立即保存待处理视图，干净状态 Ctrl+S 跳过重复上传。未修改文件格式或绕过冲突/编辑锁检查。
- 白板历史：保留 100 条上限，同时增加 16 MiB UTF-16 快照文本预算；优先丢弃最早历史并提示。当前单份快照超限时仍保留它，故预算不是整个进程内存的硬上限，也不是每个文件都保证有 100 次撤销。
- 主题：公共模块优先继承可访问父页面的主题模式和思源颜色变量，无宿主设置时回退到系统主题。监听主题属性及样式表加载，不轮询；pagehide 断开宿主监听，pageshow 重新连接。脑图画布和工具面板接入变量，不修改节点、单元格等用户内容颜色。
- 操作提示：表格冲突对话框关闭后恢复单元格焦点，表格/白板撤销按钮提供不可用原因和快捷键提示。

## 验证

1. `node --test --test-isolation=none`：82/82 通过。
2. `node tests/interaction-browser-regression.mjs`：26 组交互检查及原有 24 组白板全功能浏览器检查通过，未捕获浏览器异常。使用独立无界面 Chrome 和内存模拟思源 API，不访问用户真实附件。
3. 浏览器实测连续 5 次视图变化在停顿前不上传、停顿后合并为 1 次附件写入；无修改 Ctrl+S 不新增上传；隐藏页面在合并延迟结束前保存视图。
4. 验证文本 Unicode 光标位置及保存字节、主题明暗切换、嵌入编辑器继承父页面强调色、主题观察者暂停与恢复、真实 MindElixir 初始化及主题切换时节点颜色不变。
5. 新增模型测试覆盖行首/行尾/空文档/中文与 emoji、换行变化、撤销历史容量和条数限制、超大当前快照保留、历史分支裁剪。
6. 100,000 行文本建立索引并查询 10,000 次光标位置，在最终本机 Node 测试中约 5 ms，只构建一次索引。这是辅助函数测量，不等于真实页面帧率或总体输入延迟。
7. `pnpm build`：类型检查、构建、打包通过；补丁空白检查通过。依赖清单和锁文件未增加依赖。

## 已发现边界与未覆盖范围

- 快速离开白板再进入时，模拟环境曾出现旧页面的编辑锁尚未释放，新页面只读。卸载时的异步释放不等于已完成释放。本轮未改动锁协议，也未通过强制解锁绕过保护；保存合并测试使用独立附件，与快速重开锁问题分离。此项仍需独立处理和真实内核复测，不能宣称全部问题清零。
- 测试脚本固定无界面 Chrome 的焦点状态，并等待对话框关闭及布局帧后再输入，避免异步关闭与下一步输入重叠；冲突取消、覆盖和读取远端仍验证真实工作簿字节。
- 未执行 30 分钟压力测试、2,000 节点真实 DOM 帧率复测、实体输入法候选框、触摸屏或真实 NAS 双设备同步测试。
- 本次未修改普通思源文档/Word 导出或 PDF 内容逻辑；模型与已有回归不等于所有真实宿主界面的端到端验证。
