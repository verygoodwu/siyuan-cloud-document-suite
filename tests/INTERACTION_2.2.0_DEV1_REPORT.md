# 2.2.0-dev.1 交互优化与验证记录

日期：2026-09-08。基线：v2.1.13。本次为本地开发包，未上传 GitHub Release 或思源集市，也未替换思源当前安装目录。

## 已实现

- 表格统一能力限制与编辑锁判断：禁止超范围文件通过基础模式输入、粘贴、公式栏及结构操作绕过只读保护。
- 基础模式支持 Ctrl+S 和页面隐藏时及时保存；工具栏更名为基础工具／完整工具。
- 新增、删除、重命名工作表纳入工作簿撤销历史，恢复工作表顺序、内容和工作表元数据；历史操作可写入恢复记录。
- 行列偏移计算由反复求和改为单次累计。
- 白板选中节点后输入数字进入编辑，视图快捷键改为 Ctrl+1／Ctrl+2。
- 只读白板仍支持选择、平移、缩放、搜索和复制；写操作受限制。
- 白板 Esc、pointercancel、窗口失焦清理交互；移动、缩放尺寸、端点重连取消时恢复原状态，Alt 拖动取消时删除临时副本。
- 白板失焦释放空格临时平移；弹窗暂停后台快捷键；关闭弹窗、搜索及部分工具操作后恢复画布焦点。
- 多选颜色、字号、粗体显示混合状态；统一应用粗体，多条连接线可统一改变线型。
- 表格、脑图、白板、文本订阅编辑锁状态，失效后暂停修改，可重新获取编辑权；保存时保留原有远端内容校验。
- 中文输入法组合输入期间不执行外层键盘命令；文本查找框中的撤销不再作用于正文。
- 白板保存失败停止自动重试循环，保留恢复副本与明确的重试入口。
- 新建白板文字编辑时阻止画布默认聚焦抢走光标；关闭编辑后取消过期的延迟聚焦。

## 验证结果

1. `node --test --test-isolation=none`：78/78 通过。
2. `node tests/interaction-browser-regression.mjs`：11 组新增浏览器交互回归通过，另运行现有白板完整浏览器测试 24 组通过。未捕获浏览器异常为 0。
3. `pnpm build`：TypeScript 类型检查、构建、打包通过。
4. `git diff --check`：无补丁空白错误。

新增浏览器验证覆盖：基础模式真实输入与保存后工作簿字节检查、连续工作表撤销与重做、超范围只读、数字输入、输入法事件优先级、实际指针拖动与 Esc 恢复、失焦清理、弹窗隔离及焦点恢复、运行中锁丢失与只读平移、无需刷新恢复编辑权、Alt 拖动取消、多选粗体、文本保存与编辑锁恢复。

测试使用独立无界面 Chrome 和内存模拟思源 API；不会写入用户思源附件。既有嵌入式白板测试启用 Chrome 焦点模拟，确保原生 focus/blur 事件工作。

## 范围与限制

- 本次没有进行真实 Docker/NAS 双设备同步、移动端、物理触控板或实体中文输入法候选窗口测试；组合输入验证使用浏览器事件。
- 未重新执行半小时压力测试；现有模型性能测试通过，不等同于长期运行或 2000 节点实际帧率测试。
- 此包完成最近一轮提出的两批交互修正。前一轮较大升级（统一内部弹窗、主题实时同步、可拖动图表、白板右键菜单、完整版本恢复界面）及后续候选功能（图层锁定与隐藏等）不在本次已完成范围内。

产物：仓库根目录 `package.zip`，清单版本 `2.2.0-dev.1`。发布或本地安装时应保留此开发版本标识，避免与集市 v2.1.13 混淆。
