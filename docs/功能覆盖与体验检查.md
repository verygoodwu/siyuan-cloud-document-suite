## 本轮已经落实的体验优化

1. 正文单独拖入 PDF 时交给思源原生处理；混合/文档树导入改为标准附件链接。
2. 拖放避让数据库、只读和查询区域，避免抢占宿主交互。
3. 远程内核 PDF 导出使用浏览器打印路径；按宿主能力提供 H1–H6 标题分页。
4. 修改预览内容选项后立即禁用“确定”，直到最新预览就绪；旧响应和旧错误不会覆盖新状态，中文输入组合期间也不导出旧内容。
5. PDF 预览失败显示原因并提供“重试预览”；目录选择或导出桥接失败后可以重试，无需重开窗口。
6. 浏览器打印也等待图片与字体就绪；导出准备期间禁止修改设置，原生导出提交后避免重复点击。
