# 云文档套件 v2.3.6

- 新增与「云文档」插件搭配使用的说明。可用「云文档」侧栏浏览知识库与目录，在文档树右键菜单选择「创建文件」，用云文档套件创建和编辑电子表格、思维导图或白板。两个插件可同时启用。

# Cloud Document Suite v2.3.6

- Added instructions for using the suite alongside Cloud Docs Home. Browse notebooks and documents in its sidebar, then use the document tree's Create file menu to create spreadsheets, mind maps, or whiteboards with the suite. Both plugins can be enabled together.
