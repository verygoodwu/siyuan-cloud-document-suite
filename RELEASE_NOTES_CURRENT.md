# 云文档套件 v2.3.8

- 拖入单个文件后自动打开新文档。批量导入显示每个文件的结果，单项失败后继续处理剩余文件。
- 在批量结果中点「打开」可切换到对应文档。直接关闭弹窗会保留当前文档和目录选中状态。
- 搭配「云文档」v0.13.6 或更新版本，打开导入文档时会自动展开左侧父目录并高亮文档。

# Cloud Document Suite v2.3.8

- Single-file imports open the new document automatically. Batch imports show per-file results and continue after an individual failure.
- Select Open to switch to a specific result. Closing the dialog keeps the current document and tree selection.
- With Cloud Docs Home v0.13.6 or later, opening an imported document expands its parent folders and highlights the document in the sidebar.
